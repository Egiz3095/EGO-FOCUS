# EGO FOCUS — إيجو فوكس
**ركّز على ما يهمك.**

تطبيق عربي احترافي لإدارة المهام والإنتاجية للآيفون فقط. واجهة RTL كاملة، تخزين محلي بالكامل، بلا حساب ولا خادم.

| | |
|---|---|
| مشروع Xcode | `EGOFocus.xcodeproj` — Scheme: `EGOFocus` |
| Bundle ID | `com.egofocus.tasks` |
| المنصة | iPhone فقط — iOS 17 أو أحدث |
| التقنيات | Swift 5 · SwiftUI · SwiftData · UserNotifications · Speech · Swift Charts |
| التخزين | SwiftData محلي على الجهاز (بدون CloudKit / Supabase / أي خادم) |

## الشاشات
- **الرئيسية:** إضافة سريعة، ملخص إنتاجية اليوم، المتأخرة / اليوم / القادمة / المكتملة، حالات فارغة.
- **كل المهام:** بحث، تصفية، سحب للحذف أو الإكمال.
- **محرر المهمة:** عنوان، وصف، ملاحظات، تصنيف، أولوية، موعد، تذكيرات (عند الموعد، قبل 15/30 دقيقة، قبل ساعة، قبل يوم)، تكرار يومي/أسبوعي/شهري، إكمال/إعادة فتح، حذف.
- **التقويم:** شهري بمؤشرات حسب الأولوية، مهام اليوم المختار، المواعيد القادمة للمهام المتكررة.
- **التقارير:** يوم/أسبوع/شهر — مكتملة، قيد الانتظار، متأخرة، نسبة الإنجاز، مخطط يومي، حسب التصنيف.
- **الإعدادات:** فاتح/داكن/حسب النظام، التنبيهات، التذكير الافتراضي، الملخص الصباحي بوقت تختاره، معلومات التطبيق، بيان الخصوصية.
- **المساعد الذكي:** أوامر عربية مكتوبة أو مُملاة، معاينة قابلة للتعديل قبل الحفظ، ولا يحفظ أمراً غامضاً قبل تأكيدك.

## السلوكيات المحددة
- **التكرار الشهري يوم 29–31:** في الأشهر الأقصر تقع المهمة في آخر يوم من الشهر، ثم تعود لليوم الأصلي (31 يناير ← 28 فبراير ← 31 مارس).
- **إكمال مهمة متكررة** يسجّل الإنجاز وينقلها لموعدها التالي — لا تُنشأ نسخ مكررة.
- **التنبيهات** محلية بمعرفات ثابتة (لا تكرار)، تُعاد جدولتها عند أي تعديل وتُلغى عند الحذف أو الإكمال، مع حد أقصى 56 تنبيهاً للأقرب (حد iOS هو 64).
- **من الإشعار:** «تم التنفيذ» و«تأجيل 10 دقائق» و«عرض المهمة».
- iOS هو من يدير تسليم الإشعارات؛ قد يؤخرها وضع التركيز أو الملخص المجدول، ولا يضمن iOS تشغيل التطبيق في الخلفية.

## البناء والاختبار
```bash
xcodebuild test -project EGOFocus.xcodeproj -scheme EGOFocus \
  -destination 'platform=iOS Simulator,name=iPhone 16'
```
كل دفع إلى GitHub يشغّل `.github/workflows/ios.yml` على macOS: بناء، اختبارات وحدات وواجهة على محاكي iPhone، لقطات شاشة فاتح/داكن، وأرشيف Release.
