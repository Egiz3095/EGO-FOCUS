# المشكلات التي تم إصلاحها — EGO FOCUS 1.1

مرجع المقارنة: الحزمة الأصلية `EGO_FOCUS_Full_Project_v1.0.zip` (14 ملف Swift، لم تُبنَ بـ Xcode من قبل حسب `DELIVERY_MANIFEST.json`).

## أخطاء كانت تمنع البناء أو تسبب أعطالاً
| # | المشكلة | الإصلاح |
|---|---|---|
| 1 | `@AppStorage` بنوع `Date` (وقت الملخص الصباحي) غير مدعوم في iOS 17 ← خطأ ترجمة | التخزين كساعة ودقيقة (`Int`) مع `Binding` للـ DatePicker |
| 2 | الحذف: قراءة `item.id` **بعد** `context.delete` و`save` ← خطر انهيار SwiftData | لم يعد هناك وصول للنموذج بعد حذفه؛ التنبيهات تُزامَن من القائمة المحدّثة |

| 6 | Info.plist في مجلد Resources غير مربوط بالمشروع ومكرر | ملف Info.plist جزئي مربوط عبر `INFOPLIST_FILE` (يُدمج مع المفاتيح المولدة) |

## إعدادات المشروع
- اسم الهدف `EGOFocus` (بدل «EGO FOCUS» بمسافة) واسم الوحدة `EGOFocus`؛ الاسم الظاهر يبقى **EGO FOCUS**.
- `developmentRegion = ar` و`CFBundleLocalizations = ar` ← واجهة النظام (DatePicker، الأزرار) عربية وRTL حتى لو كانت لغة الجهاز إنجليزية.
- iPhone فقط، عمودي، iOS 17، Bundle ID `com.egofocus.tasks`، بلا Mac Catalyst ولا visionOS.
- ملف خصوصية `PrivacyInfo.xcprivacy` (مطلوب من Apple لاستخدام UserDefaults)، و`ITSAppUsesNonExemptEncryption = NO`.
- Scheme مشترك `EGOFocus` + هدفا اختبار (Unit/UI).
- لون التطبيق `AccentColor` بنسختين فاتح/داكن.

## ميزات مكتملة أو جديدة
- الرئيسية: إضافة سريعة، ملخص إنتاجية اليوم، متأخرة/اليوم/القادمة/المكتملة، حالات فارغة.
- قائمة كل المهام: بحث، تصفية، سحب للحذف/الإكمال.
- المحرر: عنوان + **وصف** (جديد) + ملاحظات، اختصارات تاريخ، تذكيرات متعددة، تفعيل/تعطيل التذكير، حذف بتأكيد، إكمال/إعادة فتح.
- التقويم: مؤشرات ملونة بالأولوية، زر «اليوم»، سحب بين الأشهر، **عرض المواعيد القادمة للمهام المتكررة**.
- التقارير: يوم/أسبوع/شهر، مكتملة/قيد الانتظار/متأخرة/النسبة، مخطط يومي (Swift Charts)، حسب التصنيف.
- الإعدادات: المظهر (يطبّق على كل النوافذ والنوافذ المنبثقة)، تفعيل التذكيرات، التذكير الافتراضي، الملخص الصباحي، عدد التذكيرات المجدولة، تنبيه تجريبي، بيان الخصوصية.
- أيقونة جديدة بلا نص (فاتح/داكن/ملوّن tinted).
