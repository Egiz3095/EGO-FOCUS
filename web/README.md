# EGO FOCUS — نسخة الويب (PWA)

نفس تطبيق EGO FOCUS كصفحة ويب تُثبَّت على الآيفون من Safari: **مشاركة ← إضافة إلى الشاشة الرئيسية**.
تفتح بملء الشاشة وبأيقونة التطبيق، وتعمل دون اتصال بعد أول فتح.

- التخزين: محلي في المتصفح على الجهاز فقط (لا خادم، لا حساب). يوجد تصدير/استعادة نسخة احتياطية من الإعدادات.
- المساعد العربي: نفس المحلل المستخدم في تطبيق iOS (منقول إلى JavaScript ومختبر بنفس الحالات).
- التنبيهات: تعمل **والتطبيق مفتوح فقط** (ومن الشاشة الرئيسية على iOS 16.4+). التذكير والتطبيق مغلق يتطلب خادماً أو نسخة iOS الأصلية.
